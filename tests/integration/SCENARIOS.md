# 주문부터 AGV 복귀까지의 통합 시험

파트를 연결한 뒤 사용할 시험 목록이다. 합의된 시험 계획은 아래 10종을 각각 3회씩 수행하는 것이다. 결과를 기록할 때 모의·실물 환경, 코드·모델·보정 버전, 회차 ID와 관련 명령·이벤트 ID를 함께 남긴다.

| 구분 | 입력 또는 상황 | 확인할 결과 |
|---|---|---|
| 정상 경로 1 | 서울 HUB 권역 주문, 검사 일치 | 3번 하역 |
| 정상 경로 2 | 대전 HUB 권역 주문, 검사 일치 | 4번 하역 |
| 정상 경로 3 | 천안 HUB 권역 주문, 검사 일치 | 5번 하역 |
| 오류 경로 1 | 필수 부품 누락 확인 | QR 오류가 함께 있어도 6번 하역 |
| 오류 경로 2 | 부품 누락 없이 주문·검사 정보 불일치 | 7번 하역. 판정 불가를 시험하면 WPF 즉시 경고도 확인 |
| 예외 1 | 투입 QR 세 번 판독 실패 | 2초 간격 재판독 후 정차 유지, WPF에서 재시도 |
| 예외 2 | 투입 QR 성공 뒤 배정 저장 실패 | 저장 성공까지 벨트 정차, 재시도해도 추가 배출 없음 |
| 예외 3 | 장비 명령 중 통신 단절 | 재연결 후 상태·이력 대조, 결과 불명 시 현장 확인 |
| 예외 4 | 같은 장비 명령 중복 수신 | 실물 동작 한 번, 기존 상태 또는 결과 반환 |
| 예외 5 | 첫 팔레트 복귀 전에 두 번째 주문 수락 | 대기열 유지, 첫 사이클 복귀 완료 후 투입 |

경로 5종은 목적지 하역에 이어 **AGV 2번 정차와 지게 85° 복귀**까지 확인한다. 각 회차에 예상 결과, 실제 결과, 성공 또는 실패, 근거 로그를 남긴다.
