# WPF 관리자 · v0.1.0

사용자 승인 무선 시험 모드에서 새 `UNO_SIM_QR_V2`가 연결되면 상단 **컨베이어 작업 시작**으로 전체 컨베이어 회차를 실행한다. 여섯 단계 표시와 QR 성공 대기·3초 모의 조립을 제공한다. Pi 교체와 UNO 재업로드 절차는 [컨베이어 시험 안내](../demos/mobot/CONVEYOR_SIMULATION.md)를 따른다.

상위 [실행 안내](../demos/mobot/README.md)를 따릅니다. `dotnet build WPF/RobotFactory.sln -c Release` 후 관리자 앱을 실행하고 내부 서버 주소·기존 계정으로 로그인합니다.

새 주문은 1초마다 조회합니다. 제작 수락, 배출 전 취소, 전체 공정 정지·해제, QR 재판독·배정 저장 재시도를 제공합니다. 주문별 공정 이력과 검사 사진, 팔레트 8개 상태를 표시합니다. 최상위 관리자는 재입고·계정·권한·보관 사진 삭제를 사용할 수 있습니다. 결과 미확인 때 이력을 선택하면 현장 확인 탭에 명령 ID가 채워집니다.

창은 최대화로 시작하고 원래 화면비를 유지하며 사용자가 크기를 조절할 수 있습니다. 네 카메라와 하단 정보 영역을 함께 배치합니다. 모의 모드 여부를 화면에 표시하며 실물 준비 부족·서버 단절에서는 운전 조작을 차단합니다. 서버 단절 시 마지막 수신 정보와 시각을 남깁니다.

WPF 세션은 서버의 로그아웃·권한 변경 정책을 따릅니다. 시간 경과만으로 만료하지 않습니다. 이전 EquipmentViewModel·AgvViewModel 소스는 빌드에서 제외했으며 새 화면은 FactoryApiClient와 DashboardViewModel을 사용합니다.

영상은 고정 0.5초 대기 없이 최신 프레임을 연속 조회하며 요청을 중첩하지 않습니다. 같은 촬영 시각의 중복 영상은 다시 디코딩하지 않고, JPEG 해독은 화면 스레드 밖에서 수행합니다. QR 카메라 제목의 fps는 실제 새 영상으로 갱신한 횟수입니다. 카메라·서버의 요청 FPS와 모니터 표시 FPS는 다를 수 있습니다.
