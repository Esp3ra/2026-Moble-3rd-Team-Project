# WPF 관리자 · 공통 통신 규약 v0.3.0


메인 PC에서 [Start-MOBOT.cmd](Start-MOBOT.cmd)를 실행해 업무 서버를 엽니다. [서버 설치와 장비 연결](../server/mobot/README.md)을 참고하세요. `dotnet build WPF/RobotFactory.sln -c Release` 후 관리자 앱을 실행하고 내부 서버 주소와 기존 계정으로 로그인합니다.

상단에는 팔레트 배출 → QR 인식 → 조립/검사 → AGV 인수 → AGV 하역 완료를 표시합니다. IR2 정차 후 AGV가 인수 명령을 접수하면 인수 단계를 표시합니다. 네 칸의 실시간 관제에는 CAM1 QR ROI, CAM2 조립, CAM3 YOLO, CAM4 전체 영상이 표시됩니다.

새 주문은 1초마다 조회합니다. 제작 수락, 배출 전 취소, 전체 공정 정지·해제, QR 재판독·배정 저장 재시도를 제공합니다. 주문별 공정 이력과 검사 사진, 팔레트 8개 상태를 표시합니다. 최상위 관리자는 재입고·계정·권한·보관 사진 삭제를 사용할 수 있습니다. 결과 미확인 때 이력을 선택하면 현장 확인 탭에 명령 ID가 채워집니다.

창은 최대화로 시작하고 원래 화면비를 유지하며 사용자가 크기를 조절할 수 있습니다. 네 카메라와 하단 정보 영역을 함께 배치합니다. 모의 모드 여부를 화면에 표시하며 실물 준비 부족·서버 단절에서는 운전 조작을 차단합니다. 서버 단절 시 마지막 수신 정보와 시각을 남깁니다.

WPF 세션은 서버의 로그아웃·권한 변경 정책을 따릅니다. 시간 경과만으로 만료하지 않습니다. 상단의 공정 단계와 조작 버튼은 업무 서버의 v1 공정 상태를 사용합니다. 첫 번째 **QR ROI** 탭에 CAM1의 확대 영상이 표시됩니다. **전체 영상 · ROI · QR 정보 열기**를 누르면 같은 CAM1 프레임의 전체 영상과 확대 영상을 시계 방향으로 90° 돌려 나란히 볼 수 있습니다. 카메라 탭의 CAM3는 정차 중 검사에 사용하는 논리 영상입니다. 물리적 검사 위치와 카메라 배치는 팀 확정 후 설정합니다.

ROI 창은 표준 `/api/v1/cameras/CAM1/frame`으로 영상을 받습니다. 서버가 ROI 확장을 제공하면 서버의 판독 영역과 판독값을 표시하고, 최상위 관리자는 정식 서버가 허용하는 시점에 판독 영역을 저장할 수 있습니다. 표준 카메라 API만 제공하는 서버에서는 드래그로 이 창의 확대 영역을 선택합니다. 회차의 실제 배정 결과는 관제 화면에서 확인합니다.

영상은 고정 0.5초 대기 없이 최신 프레임을 연속 조회하며 요청을 중첩하지 않습니다. 같은 촬영 시각의 중복 영상은 다시 디코딩하지 않고, JPEG 해독은 화면 스레드 밖에서 수행합니다. QR 카메라 제목의 fps는 실제 새 영상으로 갱신한 횟수입니다. 카메라·서버의 요청 FPS와 모니터 표시 FPS는 다를 수 있습니다.
