# WPF 화면 뼈대 검증

검증일: 2026-11-16

## 직접 확인한 사항

- .NET SDK 10.0.401에서 Release 빌드: 오류 0, 경고 0.
- Computer Use로 실제 WPF 프로그램 실행.
- 로그인 화면과 관제 화면의 미리보기 전환 확인.
- 기본 창, 최소 창 크기(설정 1000×640), 현재 모니터 최대화에서 전체 배치 확인.
- 팔레트 마지막 행과 이벤트 마지막 행이 잘리던 부분을 보정하고 다시 확인.
- 팔레트 예시 4행, 이벤트 예시 3행, 영상 자리 3개와 QR 대조 자리가 스크롤 없이 표시됨.
- 인증·생산 승인·재검·일시정지·소프트웨어 정지·컨베이어 비상정지 버튼은 비활성 상태.
- `RobotFactory.sln`을 생성하고 관리자 WPF 프로젝트를 연결한 뒤 Release 빌드 확인: 오류 0, 경고 0.
- 상단 설명 글자가 잘리던 고정 높이 76 DIP를 자동 높이·최소 92 DIP로 변경. 전체 기준 높이도 16 DIP 늘려 본문에 필요한 공간을 유지.
- 수정판의 기본 창·최소 창·최대화 상태 및 로그인/관제 화면 전환을 Computer Use로 재확인. 상단 설명 문구가 모두 표시됨.

## 검증 범위

최소 크기에서는 전체 화면이 비례 축소되어 글씨가 작아집니다. 실제 사용할 모니터에서는 최대화하여 검토하는 것이 적합합니다. Windows 배율을 별도로 바꾼 고DPI 시험은 수행하지 않았습니다.

이 결과는 화면 뼈대와 실행 검증입니다. 실제 계정, DB, 서버, 카메라, 로봇팔, 컨베이어 또는 AGV의 작동 검증이 아닙니다. 동적 목록이 늘어날 때의 페이징 정책과 API 계약은 후속 협의 사항입니다.

WPF 전용 GitHub Actions는 솔루션의 Release 빌드를 수행하도록 구성했습니다. CI 결과는 해당 커밋의 Actions 기록에서 확인합니다. CI 빌드와 실제 창의 수동 확인은 서로 다른 검증입니다.
