운전 순서

  1. RobotWorkSimulation 펌웨어를 업로드하고 시리얼 모니터를 닫습니다. 처음 USB를 연결할 때는 모터 전원을 분리하세요.
  2. USB 포트를 선택해 연결합니다. READY와 IR 통로 비움, 카메라 상태를 확인합니다.
  3. 시작 위치를 확인하고 자동 운전을 시작합니다. IR1 감지 후 구동 → 정지 대기 → 재구동 → IR2 감지 후 지연 정지 순서입니다. 시간 설정 탭에서 세 시간을 조절합니다.
  4. 중간 정지 후에는 수동 복구 버튼을 한 번씩 눌러 위치를 맞춥니다. 이동 시간은 UNO 설정값을 사용합니다. 자동 원점 검출 기능은 없습니다.
  5. 팔레트 QR·IR·장비 종료를 모두 확인한 회차만 DB를 처리합니다. DB 실패는 주문·DB 탭에서 재시도합니다.
