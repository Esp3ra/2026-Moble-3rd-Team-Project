# 컨베이어와 팔레트 푸셔 제어 준비 코드

작성일 2026년 11월 11일 / 준비 버전 0.1

## 현재 사용할 수 있는 범위

어제 시험한 UNO, STEP 5번, DIR 6번 배선과 AccelStepper를 기준으로 작성했다. 컨베이어 최고 속도는 1,000펄스/초, 가속도는 250펄스/초², 10초 자동 정지다. 이는 모터의 최대 성능을 확인한 값이 아니라 초기 실습 설정이다. 외부 전원은 사용자가 확인한 12V 2A이고, 드라이버 전류 0.5A는 초기 시험 설정이다. 적재 시 힘과 최종 전류는 미확정이다.

액추에이터는 아직 사양 미정이다. 코드는 **2선식 DC 액추에이터와 BTS7960/IBT-2 드라이버**를 가정한 준비용이며 `ACTUATOR_HARDWARE_VERIFIED = false`로 전진·복귀를 차단했다. 실제 제품이 스테핑/서보/통신형이면 이 부분을 다른 코드로 바꿔야 한다. 단순히 false를 true로 바꾸기 전에 핀·전류·끝점·이동 방향·기구 간섭을 확인해야 한다.

이 코드는 학습 및 통합 준비용 소프트웨어이다. **소프트웨어만으로 안전 등급의 비상정지를 구현했다고 볼 수 없다.** 실제 비상정지 버튼은 컨베이어와 액추에이터의 구동 전력을 독립적으로 차단하는 회로에 연결하고, UNO는 절연된 무전압 접점으로 그 상태를 읽는다. 하드웨어 차단 회로의 제품 선정과 배선은 아직 설계·검증되지 않았다. 로봇팔과 AGV의 정지는 이 코드 범위에 포함하지 않는다.

## 파일 열기

1. 모터 외부 전원을 끈 상태에서 `ConveyorActuatorController.ino`를 Arduino IDE로 연다.
2. 같은 폴더의 `Config.h`도 함께 열린다. 설정은 이 파일에서 확인한다.
3. 라이브러리 관리자에서 Mike McCauley의 AccelStepper를 설치한다.
4. 보드 Arduino Uno와 실제 COM 포트를 선택한다. 어제는 COM3이었다.
5. 컴파일 검증부터 한다. 이 준비 과정에서는 보드에 자동 업로드하지 않았다.

## 기존 컨베이어 배선

| 드라이버 | UNO | 이전 실습의 색상 |
| --- | --- | --- |
| PUL+ | D5 | 갈색 |
| PUL- | GND | 노란색 |
| DIR+ | D6 | 파란색 |
| DIR- | GND | 초록색 |

색깔보다 단자 표기를 우선한다. ENA 단자는 기존 실습처럼 연결하지 않는다. 이 구성에서 펄스를 멈춰도 모터에 유지 전류가 흐를 수 있다. 드라이버 VCC에는 모터 외부 전원이 연결되며 UNO의 5V를 연결하는 곳이 아니다. 모터선과 드라이버 스위치는 통전 중 변경하지 않는다.

## 정지 감시와 리셋 버튼

| 기능 | UNO 핀 | 준비 배선 |
| --- | --- | --- |
| 비상정지 상태 감시 | D2 | 무전압 NC 접점과 GND 사이 |
| 별도 리셋 버튼 | D3 | 순간 누름 NO 접점과 GND 사이 |

NC는 평상시 닫혀 있고 누르면 열리는 접점이다. INPUT_PULLUP을 사용해 **정상 LOW, 정지 또는 단선 HIGH**로 읽는다. 단일 회로이므로 GND 단락 같은 모든 고장을 검출하는 구조는 아니다. NO 리셋 버튼은 누를 때 GND와 연결된다. **12V나 24V 신호를 D2/D3에 직접 입력하지 않는다.** 안전 릴레이의 접점이라면 무전압 보조 접점 여부를 확인해야 한다.

버튼 및 상태 접점이 아직 없으면 D2가 HIGH이므로 코드가 잠겨서 움직이지 않는 것이 정상이다. 출고 기본값을 끄거나 D2를 점퍼로 고정해 실제 장비 비상정지를 우회하는 절차는 제공하지 않는다.

리셋 순서:
1. 물리적 비상정지 원인을 제거하고 하드웨어 회로를 해당 장비 절차대로 복구한다.
2. D2 정상 상태가 0.5초 이상 유지되어야 한다.
3. 별도 D3 리셋 버튼을 새로 누르고 놓는다. 정지 중 계속 누르고 있던 버튼을 놓기만 해서는 복구되지 않는다.
4. `READY:NEW_START_REQUIRED`가 출력된다. 리셋은 모터를 움직이지 않는다.
5. 새로운 시작 명령을 보내야 움직인다. 비상정지·리셋 시 대기 중 명령을 버린다.

## 액추에이터 배선 가안

실물 확인 전에는 연결하거나 활성화하지 않는다.

| 기능 | UNO 핀 | BTS7960 가안 |
| --- | --- | --- |
| 전진 PWM | D9 | RPWM |
| 복귀 PWM | D10 | LPWM |
| 출력 허용 | D7 / D8 | R_EN / L_EN |
| 전진 끝점 입력 | A0 | NC 접점과 GND |
| 복귀 끝점 입력 | A1 | NC 접점과 GND |

드라이버 논리 VCC는 사용 모듈 사양에 맞춰 공급하고 논리 GND를 UNO와 연결한다. 모터 전원과 M+/M-는 실제 드라이버 설명서를 따른다. RPWM 쪽이 실제 전진인지 모터선과 기구 방향에 따라 확인해야 한다. 두 PWM 방향을 동시에 출력하지 않는다. 대기·정지 때는 양 PWM을 0으로 하고 양 EN을 LOW로 둔다. 이는 소프트웨어 정지이며 구동 전력 차단을 대체하지 않는다.

끝점 NC 회로가 열리면 그 방향을 차단하고, 작동 중이면 정지한다. 다만 **끝점 도달과 선 끊김은 이 배선만으로 구분하지 못한다.** 따라서 이 이벤트를 위치 도달 완료로 보고하거나 팔레트 인계를 자동 시작하지 않는다. 양 끝점이 모두 열리면 모순/배선 오류로 잠근다.

초기 PWM은 128/255다. 실제 출력 힘이나 속도가 절반으로 보장되는 값은 아니다. 액추에이터 최대 운전 시간 3초도 사양이 정해지기 전의 시험용 상한이다. 100mm 이동 거리와 동등한 뜻이 아니며 제품의 실제 스트로크·속도와 부하로 결정해야 한다. 내장 끝점 차단만으로 UNO가 끝점을 읽을 수 있는지도 확인해야 한다.

## 명령

시리얼 모니터 9600 baud, 줄바꿈은 New Line 또는 Both NL & CR로 설정한다. 대문자 명령을 한 줄에 하나씩 전송한다. 줄바꿈 없는 명령은 실행하지 않고 0.5초 뒤 버린다.

| 명령 | 동작 |
| --- | --- |
| F | 컨베이어 지정 정방향 운전, 10초 뒤 자동 정지 |
| B | 컨베이어 반대 방향 운전, 10초 뒤 자동 정지 |
| S | 컨베이어 펄스와 액추에이터 출력 명령 즉시 정지 |
| E | 소프트웨어 정지 잠금. 해제는 D3 물리 리셋으로만 가능 |
| X | 액추에이터 전진. 기본 상태에서는 미확정 오류로 차단 |
| Y | 액추에이터 복귀. 기본 상태에서는 미확정 오류로 차단 |
| ? | 잠금, 컨베이어, 액추에이터 상태 조회 |

컨베이어와 액추에이터는 동시에 운전하지 않는다. 운전 중 새 이동 명령은 거절한다. 방향을 바꾸려면 S로 멈춘 후 새 명령을 보낸다. S와 E는 감속을 기다리지 않고 출력 명령을 정지한다. 컨베이어의 기계적 관성이나 잔류력까지 즉시 없어지는 뜻은 아니다. 자동 투입 시퀀스, 홈 복귀, 스트로크 거리 제어, 서버 연결, 통신 끊김 즉시 정지는 아직 포함하지 않았다. 대신 동작별 시간 상한을 적용했다.

오류/상태 예시:
- `BOOT:LOCKED_RESET_REQUIRED`: 부팅 후 리셋 필요
- `LOCK:ESTOP_OPEN_OR_EDGE`: NC 열림 또는 열림 신호 감지
- `READY:NEW_START_REQUIRED`: 복구 완료, 별도 시작 필요
- `ERR:ACTUATOR_UNVERIFIED`: 액추에이터 사양 미확정
- `ERR:BUSY_STOP_FIRST`: 다른 동작 중, 먼저 정지 필요
- `ACTUATOR:LIMIT_OR_WIRE_OPEN_STOP`: 끝점 입력 열림으로 정지, 위치 완료 증거 아님
- `LOCK:ACTUATOR_TIMEOUT`: 제한시간 초과, 점검 후 리셋 필요

진단 출력은 UART 공간이 부족하면 생략한다. 모터 제어와 정지 감시를 출력 대기로 막지 않기 위한 처리다. 상태가 누락되면 잠시 뒤 ?를 다시 전송한다. 이 간단한 프로토콜은 생산용 통신 ACK 또는 안전 통신 프로토콜이 아니다.

## 실물 시험 순서

보드에 업로드하기 전 배선과 출력 극성을 확인한다. 첫 출력 검증은 모터 전원을 끄거나 부하를 분리한 상태에서 한다. 액추에이터 시험은 담당자가 사양과 배선을 확정한 후에만 진행한다.

| 시험 | 기대 결과 |
| --- | --- |
| D2 미연결 상태로 부팅 후 F | 잠금 유지, 동작 없음 |
| 정상 NC 연결 후 리셋 전 F | 동작 없음 |
| 정상 상태 0.5초 후 D3 누름과 해제 | 준비 상태, 모터는 정지 유지 |
| F 후 S | 펄스 중단, 재출발 없음 |
| F 후 10초 대기 | 자동 정지 |
| 운전 중 비상정지 | 출력 명령 정지와 잠금, 실제 회로에서 구동 전력 차단 |
| 비상정지 해제만 수행 | 자동 재출발 없음 |
| 비상정지 중 리셋 누른 채 해제 | 리셋 불허, 새 누름과 해제 필요 |
| E 뒤 F를 연이어 보냄 | 잠금 유지, 후속 명령 실행 안 함 |
| 부팅 시 리셋 버튼 누른 채 전원 인가 | 놓기만 해서는 리셋 안 됨 |
| 액추에이터 기본 설정으로 X/Y | 미확정 오류, 출력 없음 |
| 활성화 후 양 끝점 열림 | 오류 잠금 |
| 활성화 후 목표 끝점 입력 열림 | 해당 방향 정지, 자동 위치 완료 처리 없음 |
| 활성화 후 액추에이터 3초 초과 | 출력 정지, 오류 잠금 |
| 컨베이어 중 X 또는 액추에이터 중 F | 동시 동작 차단 |
