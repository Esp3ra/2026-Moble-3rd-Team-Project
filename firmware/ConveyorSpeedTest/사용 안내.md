# 컨베이어 속도 탐색 — a 실행 / s 정지

액추에이터 시험 코드는 그대로 두고 추가한 별도 UNO 스케치다. 이번에는 컨베이어만 시험하며 액추에이터를 구동하지 않는다. UNO에는 프로그램 하나만 올라가므로 이 스케치를 업로드하면 이전 액추에이터 시험 프로그램이 교체된다.

## 시험 목표

최종 통합 테스트의 벨트 운전 시간은 10초로 한다. 그 전에 팔레트를 안정적으로 운반하는 가장 높은 속도를 탐색한다. 코드가 정해진 시간 동안 펄스를 보냈다고 모터/벨트가 정상이라고 판정하지 않는다. 모터 피드백 센서는 없으므로 사람이 실제 움직임을 확인한다.

## 준비

1. 두 모터의 외부 전원은 분리한 채 UNO USB로 업로드한다. 라이브러리 관리자에 AccelStepper 1.64가 필요하다.
2. 컨베이어 배선: PUL+ D5, DIR+ D6, PUL-/DIR- GND. 기존 실습의 마이크로스텝과 전류 설정은 임의 변경하지 않는다.
3. 액추에이터의 12V 전원은 계속 분리한다. 이 코드는 L298N D9/D7/D8도 LOW로 유지한다.
4. 시리얼 모니터 115200 / New Line. 컨베이어 구동부에 손/도구가 걸리지 않도록 두고 벨트 외부 전원을 연결한다.
5. 첫 시험은 빈 벨트로 한다. 이후 실제 팔레트 부하에서 다시 확인한다. 외부 전원 분리는 언제든 할 수 있도록 둔다.

## 조작

- **a**: 현재 목표 속도로 가속 운전. 시작부터 **10초 후 자동 정지**한다.
- **s**: 중간 정지. 자동 복귀나 재출발은 없다. 중단한 시험은 다음 속도로 올리지 않는다.
- 운전 중 a는 거절하며 추가 시험을 예약하지 않는다.
- 정상적으로 10초가 끝나면 다음 a에서 목표를 250펄스/초 올린다. 자동으로 다음 시험을 시작하지 않는다. 속도를 올릴지는 사람이 현재 시험의 정상 동작을 확인하고 결정한다.

목표 순서: **1000 → 1250 → 1500 → 1750 → 2000 → 2250 → 2500 → 2750 → 3000펄스/초**.

3000은 첫 탐색용 코드 상한일 뿐 실제 장비의 최대값이 아니다. 상한에서도 안정적이면 추가 탐색 범위를 정한다. 상한 이후 a는 같은 3000 목표로 시험하며 더 올리지 않는다. UNO를 재시작하면 1000부터 다시 시작한다.

출력 예:

```
TEST_TARGET_PPS:1000
DONE_TIME_NOT_VERIFIED_PPS:1000
NEXT_A_TARGET_PPS:1250
```

DONE은 10초가 끝났다는 뜻이다. 실제 정상 구동/목표 속도 도달/탈조 없음의 증거가 아니다. 목표 속도는 입력 펄스 기준이며 mm/s를 직접 나타내지 않는다.

## 관찰·기록

| 목표 pps | 시작 시 걸림 | 가속 후 벨트가 연속 이동 | 이상 소음·진동 | 팔레트 미끄러짐·걸림 | 판단 |
| --- | --- | --- | --- | --- | --- |
| 1000 | | | | | |
| 1250 | | | | | |
| 1500 | | | | | |
| 이후 | | | | | |

모터에서 소리만 나고 벨트가 멈추거나 움직임이 불규칙하면 s로 멈추고 다음 a를 보내지 않는다. 그 목표 속도와 직전 안정적이었던 값을 기록한다. 자동 정지 후에 이상을 발견했다면 다음 목표는 이미 올라갔으니 다음 a를 누르지 말고 값을 알려준다.

가속도는 500펄스/초², 10초에는 가속 시간이 포함된다. 이론상 1000 도달 약 2초, 3000 도달 약 6초지만 실제 라이브러리 호출 속도/부하로 달라진다. 시작·가속 중의 실패와 일정 속도에서의 실패를 구분한다. 가속 중 실패만으로 일정 속도에서의 최대값을 결론 내리지 않는다.

처음 이상이 생긴 값이 장비 최대값으로 확정되는 것도 아니다. 전원·전류·가속도·벨트 장력·팔레트 부하 조건을 고정해 직전 안정값과 주변 값을 재시험하고 실제 운전 속도는 여유를 두고 정한다. 코드에서 드라이버 전압이나 전류를 올리지는 않는다.

## 한계·검증

STEP 출력 정지는 모터 드라이버 전력 차단이 아니다. ENA를 연결하지 않은 기존 구성에서는 유지 전류가 남을 수 있다. 물리 비상정지, 실제 회전/벨트 속도 감지, 자동 고장 검출은 이 스케치 범위 밖이다.

로컬 UNO 컴파일과 GitHub CI를 확인하며 실제 장치 시험은 아직 미실행이다. 최대 속도는 아직 측정되지 않았다. 통합 액추에이터 왕복 → 컨베이어 10초 운전 코드는 속도 시험 후 구성한다. 기존 ActuatorJogTest와 OrderPalletFeeder는 변경하지 않는다.
