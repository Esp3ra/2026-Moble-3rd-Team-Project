# 주문·카메라 신호 기반 팔레트 투입 코드

기존 `ActuatorJogTest`는 변경하지 않고 별도 스케치로 추가했다. UNO에는 한 번에 프로그램 하나만 올라간다. 이 스케치를 업로드하면 기존 시험 프로그램을 대체하므로 당장은 업로드할 필요 없다.

## 동작

**주문 명령 → 전진 → 카메라의 팔레트 도착 신호 → 복귀** 구조다.

| 상태 | 모터 출력 / 다음 동작 |
| --- | --- |
| LOCKED | 부팅·정지 후 출력 꺼짐. 원위치 확인 필요 |
| IDLE | 주문 대기 |
| PUSHING | 설정된 방향으로 전진. 카메라 신호가 오면 일찍 정지 가능 |
| WAIT_CAMERA | 최대 전진 시간 경과로 출력 정지. 카메라 신호를 기다림 |
| REVERSAL_PAUSE | 카메라 신호 수신 후 출력 끄고 역전 대기 |
| RETURNING | 설정 시간 동안 복귀 |
| RETURN_TIME_ELAPSED | 복귀 출력 시간 종료. 실제 원위치 도착은 미확인 |
| FAULT_CAMERA_TIMEOUT | 주문 수락 후 카메라 대기 제한시간 초과. 출력 정지·복귀 안 함 |

전진 시간이 지났다는 이유만으로 복귀하지 않는다. 카메라 신호가 필수다. 카메라 신호가 전진 도중 오면 즉시 전진 출력을 끄고 역전 대기 후 복귀한다. 카메라가 끝내 인식하지 못하면 멈춘 상태에서 오류로 전환한다.

복귀 시간만으로 원위치를 증명하지 않으므로 자동으로 다음 주문을 허용하지 않는다. 현재는 사람이 원위치를 확인한 후 HOME 명령으로 준비 상태로 만든다. 최종 연동에서는 실제 복귀 센서 확인으로 이 단계를 대체해야 한다. HOME 명령은 원점으로 이동시키는 명령이 아니다.

## 기본 설정과 배선

`Config.h`의 **DRY_RUN = true**가 기본이다. 이 모드에서는 상태 전이만 시뮬레이션하고 모터 출력은 항상 꺼져 있다.

| 설정 | 현재값 | 의미 |
| --- | --- | --- |
| PUSH_MAX_MS | 2000 | 전진 출력 시간 상한, 나중에 실제 팔레트로 설정 |
| RETURN_MS | 2000 | 복귀 출력 시간, 나중에 설정 |
| REVERSAL_PAUSE_MS | 500 | 전진 출력 종료 후 반대 방향 출력 전 대기 |
| CAMERA_TIMEOUT_MS | 30000 | **주문 수락 시점부터** 카메라 신호를 허용하는 제한시간 |
| MOTOR_PWM | 255 | PWM 최대 듀티 |
| PUSH_IS_J | true | 이전 시험 J 방향을 전진으로 가정. 실제 방향 확인 후 설정 |

위 시간은 미보정 예시이며 이동 거리나 끝점 도착을 보장하지 않는다. 실제 구동은 방향·스트로크 여유·전진/복귀 시간·중지 수단을 확인한 뒤 DRY_RUN을 false로 바꾼다. 모터 전원을 분리한 상태에서 업로드한다.

배선은 동일하다: **L298N ENA D9 / IN1 D7 / IN2 D8 / 공통 GND**. ENA 캡 제거, 전원 단자 옆 5V 레귤레이터 점퍼캡 장착. +5V를 UNO에 연결하지 않는다. UNO는 USB 전원이다. 이 스케치는 컨베이어를 제어하지 않으며 단독 시험 때 컨베이어 모터 전원은 분리한다.

## 상위 제어기와의 명령 가안

다른 담당의 API·DB는 수정하지 않았다. 아래는 **합의 전 로컬 USB 시리얼 계약 제안**이다. 라즈베리파이/PC가 주문과 카메라 판독을 연결해 명령을 보내며, UNO가 직접 QR/영상/DB를 처리하지 않는다.

115200 baud, ASCII, 한 줄에 한 명령, 줄 끝 LF 또는 CRLF. 명령은 대문자이며 공백은 아래 형식을 그대로 따른다. 수신 명령 길이는 47문자 이내이고 0.5초 이상 끊긴 부분 명령은 버린다. 한 명령 응답을 확인한 후 다음 명령을 보낸다.

| 명령 예시 | 발신 주체 / 의미 |
| --- | --- |
| HOME | 작업자가 실제 원위치를 확인한 후 상위 제어기가 전달. 출력 없이 준비 상태로 전환 |
| ORDER 101 | 주문 시스템이 해당 투입 작업 시작 요청 |
| PALLET 101 | 카메라 담당 프로그램이 **해당 작업의 팔레트가 지정 구역에 도착했음**을 확인 |
| STATUS | 상태·작업 번호·DRY/LIVE 조회 |
| STOP | 전체 동작 취소·출력 정지·잠금 |
| ESTOP | STOP과 같은 소프트웨어 잠금. 실제 비상정지 회로가 아님 |

작업 번호는 **1~4294967295의 증가하는 양의 정수**다. DB 주문 번호 그대로를 강제하는 것이 아니라 상위 제어기가 부여하는 투입 시퀀스다. 같은 주문이 여러 팔레트라면 팔레트 투입마다 별도 시퀀스가 필요하다. 최종 형식은 담당자 합의로 조정한다.

- 같은 번호 ORDER 재수신: `OK DUPLICATE_NO_RESTART`, 다시 움직이지 않음.
- 과거 번호, 다른 작업의 PALLET: `ERR JOB_ID`.
- 동작 중 새 주문: `ERR NOT_READY`. 내부 주문 큐가 없으므로 상위 제어기가 대기시킨다.
- 카메라 이벤트 중복은 복귀 시간을 연장하거나 새 복귀를 시작하지 않음.
- STOP/FAULT 후 늦게 온 PALLET은 모터를 다시 켜지 않음.
- 복귀 완료 시간 이후 HOME 확인 전 새 주문을 거절함.
- HOME/STOP은 수신 대기 명령을 버리므로 여러 명령을 한꺼번에 붙여 보내지 않음.
- 부팅 때 자동 전진·자동 복귀하지 않음.

상태 출력 예: `STATE WAIT_CAMERA JOB 101 DRY`. `OK`는 명령 수락이며 물리 투입 완료가 아니다. `RETURN_TIME_ELAPSED`도 복귀 출력 시간 종료일 뿐이다. 로그/응답은 UART 공간이 부족하면 생략될 수 있으므로 상위 제어기는 STATUS 조회로 복구해야 한다. 확실한 재전송/ACK 계약과 흐름 제어는 최종 통합 때 합의해야 한다. 상태를 모른다고 새 번호로 주문을 재발행하면 중복 투입될 수 있다.

중복 방지 기록은 UNO RAM 안에만 있으며 재부팅 후 사라진다. 전원 재가동 시 상위 시스템은 미완료 작업과 실제 팔레트/막대 상태를 확인하고 오래된 전송 큐를 비워야 한다. 이전 ORDER를 자동 재전송하지 않는다. 완전한 영속 중복 방지나 연결 세션 인증을 구현한 것으로 간주하지 않는다.

## 모터 없는 흐름 시험

기본 DRY_RUN을 유지하고 모터 전원을 분리한다. Arduino IDE에서 이 폴더의 OrderPalletFeeder.ino를 열고 UNO로 업로드하거나, 컴파일만 확인할 수 있다.

아래는 시리얼 모니터에 **각 줄을 따로** 보내는 순서다.

1. `STATUS` → LOCKED / DRY.
2. `HOME` → OK. 실제 구동 때는 사람이 원위치를 확인한 뒤에만 보낸다.
3. `ORDER 101` → OK. STATUS로 PUSHING 확인.
4. 2초 후 `STATUS` → WAIT_CAMERA. 시간이 지나도 복귀하지 않는지 확인.
5. 주문 수락 후 30초가 되기 전에 `PALLET 101` → OK.
6. 0.5초 역전 대기 후 RETURNING, 2초 후 RETURN_TIME_ELAPSED.
7. `ORDER 102` → NOT_READY. 원위치 확인 후 HOME을 보내면 새 주문 가능.

추가 확인: 카메라 신호를 안 보내면 FAULT_CAMERA_TIMEOUT, 다른 번호 PALLET은 거절, 동작 중 STOP 후 기다려도 자동 복귀 없음, HOME 후 같은 ORDER 번호를 다시 보내도 중복 구동 없음.

## 범위와 검증

외부 카메라 인식 자체, 주문 서버 연결, 실제 원위치 센서, 팔레트 유무/컨베이어 여유 확인, 물리 비상정지 회로, 통신 단절 즉시 정지, 영속 중복 방지는 아직 포함하지 않았다. 출력 시간 상한과 카메라 대기 제한시간은 적용했다. 이 코드는 연동 구조 초안이며 무인 생산 운전용 완성 코드가 아니다.

FeederLogic.h는 하드웨어와 분리한 상태 로직이다. firmware/tests/feeder_logic_test.cpp는 중복 주문, 번호 불일치, 카메라 조기/지연 신호, 시간 초과, 역전 대기, 각 단계 정지, 복귀 후 잠금, 시간 카운터 순환을 호스트에서 검증한다. 호스트 테스트·UNO 컴파일·실제 장치 시험 결과는 구분한다. 실제 주문·카메라·모터를 연결한 시험은 아직 수행하지 않았다.
