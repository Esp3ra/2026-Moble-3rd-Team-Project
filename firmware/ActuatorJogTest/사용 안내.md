# 액추에이터 2초 조그 시험

기존 타 팀 코드 대신 사용하는 UNO + L298N 단독 실습용 코드다. 통합 컨트롤러와 동시에 업로드하는 파일이 아니다. 이 스케치를 업로드하면 기존 UNO 프로그램을 대체한다.

## 연결

- ENA → UNO D9. ENA 점퍼캡 제거.
- IN1 → D7, IN2 → D8. D6는 컨베이어 DIR이므로 사용하지 않는다.
- 드라이버 GND → UNO GND와 어댑터 음극 공통 연결.
- 어댑터 양극 → 드라이버 +12V. 드라이버 +5V는 비워둔다.
- 액추에이터 두 선 → OUT1/OUT2.
- 전원 단자 옆 5V 레귤레이터 점퍼캡은 장착한다. ENA 캡은 제거한다. 사용자 측정에서 +5V/GND가 처음 0V였고 점퍼 복구 후 5V로 확인되었다.
- 외부 리미트 입력은 이 단독 시험 코드에서 사용하지 않는다. UNO에 없는 D24도 사용하지 않는다.

## 먼저 할 일

1. **컨베이어 드라이버의 모터 전원은 분리**한다. 컨베이어 STEP D5는 LOW로 두며 이 코드는 컨베이어를 구동하지 않는다.
2. 액추에이터 12V 어댑터도 콘센트에서 빼둔다. ENA/IN1/IN2/GND 배선을 확인한다.
3. 액추에이터에 팔레트·밀판 등 부하를 연결하지 않고, 시험 중 본체가 굴러가거나 막대가 물건/손에 닿지 않도록 둔다.
4. Arduino IDE에서 `ActuatorJogTest.ino`를 열고 보드 UNO와 실제 포트를 선택한다. 추가 라이브러리는 필요 없다.
5. USB만 연결하고 업로드한다. 업로드는 모터 전원이 분리된 상태에서 진행한다.
6. 시리얼 모니터를 **115200 baud / New Line**으로 설정한다. `?`를 보내 `LOCKED:R_REQUIRED`를 확인한다. 부팅 메시지는 모니터를 여는 시점에 따라 놓칠 수 있다.
7. 출력이 정지한 상태에서 12V 어댑터를 켠다. 이때 명령 없이 움직이면 즉시 어댑터 전원을 빼고 배선을 확인한다.

## 첫 시험

명령은 소문자로 한 줄에 하나만 전송한다. 여러 명령을 한꺼번에 붙여 보내지 않는다.

| 명령 | 동작 |
| --- | --- |
| r | 다음 1회의 조그 허용. 스스로 움직이지 않음. 10초 후 허용 만료 |
| j | 방향 J로 최대 2초 운전 후 자동 정지·잠금 |
| k | 반대 방향 K로 최대 2초 운전 후 자동 정지·잠금 |
| s | 출력 정지·잠금, 대기 명령 제거 |
| e | 소프트웨어 정지·잠금. 물리 비상정지 아님 |
| ? | 현재 상태 조회 |
| d / u | 15초 전체 이동은 오류 메시지로 거절 |

`r` 전송 → 응답 확인 → `j` 전송 → 정지 확인 순서로 한 번만 시험한다. 반대로 움직이려면 정지 후 다시 `r` → `k`를 보낸다. J/K가 실제 전진/복귀 중 어느 쪽인지는 실물로 확인한다. 끝점 방향으로 반복 구동하지 않는다. 움직이지 않고 소리만 나면 반복하지 말고 전원을 빼고 확인한다.

## 한계와 후속 작업

- 이 코드는 물리 비상정지/끝점 스위치 없이 짧은 무부하 동작을 확인하는 실습용이다. 통합 공정·무인 운전에 사용하지 않는다.
- `s/e`는 USB 시리얼과 실행 중인 프로그램에 의존하며 안전 등급의 비상정지가 아니다. 이상 시 바로 분리할 수 있도록 어댑터 전원 차단 위치를 확보한다.
- 2초는 위치나 이동 거리 보장이 아니다. 내장 끝점 차단, 기동/걸림 전류, 실제 이동 방향과 속도는 아직 실측하지 않았다.
- 정지/조그 종료/재허용 시 수신 대기 명령을 지워 재출발을 방지한다. 부팅과 조그 종료 후 반드시 새 r 명령이 필요하다.
- 출력/정지 감시를 막는 `delay()`·운전용 `while`을 사용하지 않는다. 로그는 UART가 바쁘면 생략될 수 있다. 상태는 ?로 다시 조회한다.
- 컨베이어와 물리 정지/리셋, NC 끝점을 함께 사용할 때는 별도 `ConveyorActuatorController`를 사용한다. 그 코드는 아직 미확인 배선을 전제로 잠금/비활성화되어 있다.

## 정지 시험 순서

양방향 0.5초 동작은 사용자가 확인했다고 보고했다. 현재 2초 설정으로 운전 중 s 정지를 확인한다. 아래 항목은 아직 실행 결과가 아닌 시험 절차다.

1. 모터 전원을 분리한 채 수정된 스케치를 USB로 업로드한다.
2. 컨베이어 전원은 계속 분리하고, 액추에이터를 무부하로 둔다. 끝점으로 밀어붙이지 않도록 이동할 공간이 있는 방향을 선택한다.
3. 12V 연결 후 r → j(또는 k)를 보내고, 움직이기 시작하면 s를 입력해 Enter를 누른다. 명령을 한꺼번에 붙여 보내지 않는다.
4. STOP:LOCKED 출력과 2초 자동 정지 전에 실제로 멈췄는지 확인한다. 자동 정지와 구분되지 않았다면 정지 시험 통과로 기록하지 않는다.
5. 새 r 없이 j/k를 보내 ERR:SEND_R_FIRST가 출력되고 움직이지 않는지 확인한다.
6. 새 r → 반대 방향 명령을 보내 2초 후 자동 정지하는지 확인한다. 각 시험은 한 번씩만 진행한다.
7. 시험을 마치면 12V 전원을 뺀다. e는 별도 소프트웨어 잠금이며 실제 비상정지 버튼 시험이 아니다.

검증 범위: 0.5초 양방향 동작은 사용자 보고이며 직접 장치 측정 결과가 아니다. 최신 2초 설정의 실물 정지·자동 정지·재출발 차단 시험은 아직 미실행이다.
