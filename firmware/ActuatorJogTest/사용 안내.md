# 액추에이터 테스트 — a 실행 / s 정지

움직이는 명령은 **a 하나**다. r 준비, j/k, q/w, d/u 명령은 삭제했다. 기존 주문·카메라 연동 스케치는 별도로 유지한다.

## 사용

1. 12V 모터 전원을 분리한 채 ActuatorJogTest.ino를 USB로 UNO에 업로드한다. 컨베이어 모터 전원은 분리한다.
2. 시리얼 모니터를 **115200 baud / New Line**으로 설정한다.
3. 막대의 첫 방향 이동 여유를 확인하고 부하/손/주변 물건을 치운 뒤 12V를 연결한다. 명령 없이 움직이지 않아야 한다.
4. **a + Enter**: 첫 방향 11.5초 → 출력 정지 0.5초 → 반대 방향 11.5초 → 종료. 한 번만 왕복한다. 총 약 23.5초다.
5. **s + Enter**: 어느 단계에서든 즉시 출력 명령을 정지하고 남은 사이클과 대기 명령을 취소한다. 자동 재출발/자동 복귀하지 않는다.
6. 정상 종료 후 새 a를 보내면 새 사이클을 시작한다. 실행 중 a는 거절하며 다음 실행으로 예약하지 않는다.
7. 시험 종료 후 12V를 뺀다.

정지 후 새 a는 처음 방향부터 새 사이클을 시작한다. 중간 정지한 위치에서 무조건 다시 실행하지 말고 막대 위치와 이동 여유를 먼저 확인한다. 부팅/USB 재연결 시에도 a를 받기 전까지 출력은 꺼져 있다.

## 설정과 배선

- AUTO_FORWARD_MS = 11500UL / AUTO_REVERSE_MS = 11500UL. 사용자 요청에 맞춘 시간 설정이며 위치 감지 값이 아니다.
- DIRECTION_PAUSE_MS = 500UL / SPEED = 255.
- AUTO_FIRST_IS_J = true: 기존 J 전기 방향이 먼저다. 실제 전진 방향을 확인한 후 필요 시 false로 바꾼다.
- ENA → D9 (ENA 점퍼캡 제거), IN1 → D7, IN2 → D8, 공통 GND.
- 전원 단자 옆 5V 레귤레이터 점퍼캡은 장착한다. +5V 단자는 UNO와 연결하지 않는다. 모터는 외부 12V, UNO는 USB 전원.

## 메시지

- READY A=ROUND_TRIP S=STOP: 대기
- AUTO:FIRST_11500MS / AUTO:PAUSE_500MS / AUTO:RETURN_11500MS: 진행 단계
- AUTO_DONE:READY_A: 시간 기반 사이클 종료
- STOPPED:READY_A: s로 취소. 실제 원위치에 있다는 뜻은 아님
- BUSY:NO_QUEUED_RESTART: 동작 중 a 거절
- ERR:USE_A_OR_S: 삭제된 명령/알 수 없는 명령 거절

## 시험 범위

내장 끝점 차단 여부는 미확정이다. 움직임이 끝에서 멈추면 s로 정지하고 끝에 걸린 채 유지하지 않는다. 11.5초 왕복은 원위치 복귀나 100mm 이동을 보장하지 않는다. 물리 비상정지/끝점 센서/주문 연동은 이 단독 스케치에 포함하지 않는다. s는 USB와 프로그램에 의존하는 소프트웨어 정지다.

새 단일 실행 명령 방식의 실물 시험은 아직 미실행이다. 사용자 보고로 확인한 이전 버전의 양방향 구동·정지 동작과 구분한다. 실제 스케치 소스를 포함하는 호스트 테스트로 부팅 정지, a 1회 실행, 정확한 단계 경계, 정지 대기 중 s 취소, 동작 중 a 거절, 오래된 명령 거절을 확인한다. 호스트 모의 시험은 실제 장치 검증이 아니다.
