# 액추에이터 조그·자동 왕복 시험

기존 타 팀 코드 대신 사용하는 UNO + L298N 단독 실습용 코드다. 통합 컨트롤러와 동시에 업로드하는 파일이 아니다. 이 스케치를 업로드하면 기존 UNO 프로그램을 대체한다.

## 연결

- ENA → UNO D9. ENA 점퍼캡 제거.
- IN1 → D7, IN2 → D8. D6는 컨베이어 DIR이므로 사용하지 않는다.
- 드라이버 GND → UNO GND와 어댑터 음극 공통 연결.
- 어댑터 양극 → 드라이버 +12V. 드라이버 +5V는 비워둔다.
- 액추에이터 두 선 → OUT1/OUT2.
- 전원 단자 옆 5V 레귤레이터 점퍼캡은 장착한다. ENA 캡은 제거한다. 사용자 측정에서 +5V/GND가 처음 0V였고 점퍼 복구 후 5V로 확인되었다.
- 외부 리미트 입력은 이 단독 시험 코드에서 사용하지 않는다. UNO에 없는 D24도 사용하지 않는다.

## 먼저 할 일

1. **컨베이어 드라이버의 모터 전원은 분리**한다. 컨베이어 STEP D5는 LOW로 두며 이 코드는 컨베이어를 구동하지 않는다.
2. 액추에이터 12V 어댑터도 콘센트에서 빼둔다. ENA/IN1/IN2/GND 배선을 확인한다.
3. 액추에이터에 팔레트·밀판 등 부하를 연결하지 않고, 시험 중 본체가 굴러가거나 막대가 물건/손에 닿지 않도록 둔다.
4. Arduino IDE에서 `ActuatorJogTest.ino`를 열고 보드 UNO와 실제 포트를 선택한다. 추가 라이브러리는 필요 없다.
5. USB만 연결하고 업로드한다. 업로드는 모터 전원이 분리된 상태에서 진행한다.
6. 시리얼 모니터를 **115200 baud / New Line**으로 설정한다. `?`를 보내 `LOCKED:R_REQUIRED`를 확인한다. 부팅 메시지는 모니터를 여는 시점에 따라 놓칠 수 있다.
7. 출력이 정지한 상태에서 12V 어댑터를 켠다. 이때 명령 없이 움직이면 즉시 어댑터 전원을 빼고 배선을 확인한다.

## 첫 시험

명령은 소문자로 한 줄에 하나만 전송한다. 여러 명령을 한꺼번에 붙여 보내지 않는다.

| 명령 | 동작 |
| --- | --- |
| r | 다음 1회의 조그 또는 자동 왕복 허용. 스스로 움직이지 않음. 10초 후 허용 만료 |
| j | 방향 J로 최대 2초 운전 후 자동 정지·잠금 |
| k | 반대 방향 K로 최대 2초 운전 후 자동 정지·잠금 |
| a | 첫 방향 5초 → 출력 정지 0.5초 → 반대 방향 5초 → 정지·잠금, 1회만 실행 |
| s | 출력 정지·잠금, 대기 명령 제거 |
| e | 소프트웨어 정지·잠금. 물리 비상정지 아님 |
| ? | 현재 상태 조회 |
| q / w | J / K 방향으로 0.5초 미세 이동, 새 r 필요 |
| d / u | J / K 방향 장시간 시험. END_CUTOFF_VERIFIED=false인 현재는 거절 |

`r` 전송 → 응답 확인 → `j` 전송 → 정지 확인 순서로 한 번만 시험한다. 반대로 움직이려면 정지 후 다시 `r` → `k`를 보낸다. J/K가 실제 전진/복귀 중 어느 쪽인지는 실물로 확인한다. 끝점 방향으로 반복 구동하지 않는다. 움직이지 않고 소리만 나면 반복하지 말고 전원을 빼고 확인한다.

## 한계와 후속 작업

- 이 코드는 물리 비상정지/끝점 스위치 없이 짧은 무부하 동작을 확인하는 실습용이다. 통합 공정·무인 운전에 사용하지 않는다.
- `s/e`는 USB 시리얼과 실행 중인 프로그램에 의존하며 안전 등급의 비상정지가 아니다. 이상 시 바로 분리할 수 있도록 어댑터 전원 차단 위치를 확보한다.
- 2초는 위치나 이동 거리 보장이 아니다. 내장 끝점 차단, 기동/걸림 전류, 실제 이동 방향과 속도는 아직 실측하지 않았다.
- 정지/조그 종료/재허용 시 수신 대기 명령을 지워 재출발을 방지한다. 부팅과 조그 종료 후 반드시 새 r 명령이 필요하다.
- 출력/정지 감시를 막는 `delay()`·운전용 `while`을 사용하지 않는다. 로그는 UART가 바쁘면 생략될 수 있다. 상태는 ?로 다시 조회한다.
- 컨베이어와 물리 정지/리셋, NC 끝점을 함께 사용할 때는 별도 `ConveyorActuatorController`를 사용한다. 그 코드는 아직 미확인 배선을 전제로 잠금/비활성화되어 있다.

## 정지 시험 순서

양방향 0.5초 동작은 사용자가 확인했다고 보고했다. 현재 2초 설정으로 운전 중 s 정지를 확인한다. 아래 항목은 아직 실행 결과가 아닌 시험 절차다.

1. 모터 전원을 분리한 채 수정된 스케치를 USB로 업로드한다.
2. 컨베이어 전원은 계속 분리하고, 액추에이터를 무부하로 둔다. 끝점으로 밀어붙이지 않도록 이동할 공간이 있는 방향을 선택한다.
3. 12V 연결 후 r → j(또는 k)를 보내고, 움직이기 시작하면 s를 입력해 Enter를 누른다. 명령을 한꺼번에 붙여 보내지 않는다.
4. STOP:LOCKED 출력과 2초 자동 정지 전에 실제로 멈췄는지 확인한다. 자동 정지와 구분되지 않았다면 정지 시험 통과로 기록하지 않는다.
5. 새 r 없이 j/k를 보내 ERR:SEND_R_FIRST가 출력되고 움직이지 않는지 확인한다.
6. 새 r → 반대 방향 명령을 보내 2초 후 자동 정지하는지 확인한다. 각 시험은 한 번씩만 진행한다.
7. 시험을 마치면 12V 전원을 뺀다. e는 별도 소프트웨어 잠금이며 실제 비상정지 버튼 시험이 아니다.

검증 범위: 0.5초 양방향 동작은 사용자 보고이며 직접 장치 측정 결과가 아니다. 최신 2초 설정의 실물 정지·자동 정지·재출발 차단 시험은 아직 미실행이다.

## 자동 왕복 시험

현재 사용자는 2초 자동 정지, s 정지 후 재시작 차단을 정상이라고 보고했다. 자동 왕복은 새 기능으로 아직 실물 시험 전이다.

- 상단 `AUTO_FORWARD_MS = 5000UL`, `AUTO_REVERSE_MS = 5000UL`로 각 방향 시간을 조절한다. `DIRECTION_PAUSE_MS = 500UL`은 역전 전 정지 시간이다.
- 기본 첫 방향은 J, 복귀 방향은 K다. 실제 전진/복귀 대응은 사용자가 확인해야 한다. `AUTO_FIRST_IS_J = false`로 첫 방향을 K로 바꿀 수 있다.
- 12V를 분리한 채 업로드하고 115200 / New Line을 사용한다. 컨베이어 전원은 분리한다.
- 막대가 첫 방향으로 5초 이동할 여유가 있는 위치에서 무부하로 시작한다. 라벨 무부하 속도 기준 약 40mm이지만 실제 이동량은 보장하지 않는다. 위치 여유를 확인할 수 없다면 먼저 2초 조그로 위치를 확인하거나 자동 시간을 줄인다. 외부 끝점 감시/내장 차단 검증은 아직 없다.
- r 전송 → 응답 확인 → 10초 이내 a 전송. 여러 명령을 한 번에 붙여 보내지 않는다.
- AUTO:FIRST → AUTO:PAUSE → AUTO:RETURNING → AUTO_DONE:LOCKED_R_REQUIRED 순서로 한 사이클 후 잠긴다. 무한 반복하거나 부팅 시 자동 시작하지 않는다.
- 첫 이동, 정지 대기, 복귀 중 어느 단계에서도 s/e는 전체 사이클을 취소한다. 정지 대기 중에는 r/j/k/a를 거절하며 s 후 기다려도 자동 복귀하지 않아야 한다.
- 같은 시간의 왕복은 원위치 복귀 보장이 아니다. 위치가 누적해서 어긋날 수 있으므로 반복 공정에는 홈/위치 피드백이 필요하다.

수동 확인 항목(아직 미실행): r 없이 a 차단, 5초/정지 0.5초/반대 5초/최종 잠금, 각 단계의 s 취소, s 후 자동 복귀 없음, 새 r 없이 재실행 차단, 운전/대기 중 추가 이동 명령 거절.

## 최대 길이 확인 준비

이 액추에이터는 스트로크 100mm, 무부하 속도 8mm/s로 표기되어 있어 이상적인 전체 이동 시간은 12.5초다. L298N 전압 강하·부하·초기 위치로 실제 시간은 달라진다. 100mm는 완전 복귀 위치부터의 **이동 거리**이지 본체를 포함한 전체 길이가 아니다.

`FULL_STROKE_TEST_MS = 15000UL`을 장시간 시험 상한 예시로 추가했다. 이 시간이 지나면 무조건 출력을 정지한다. 그러나 시간만으로 최대 길이를 인지하거나 끝점에 도달할 때까지 자동 연장하는 기능은 없다.

현재 제품 설명과 라벨에서 내장 끝점 차단을 확인하지 못했으므로 **END_CUTOFF_VERIFIED=false**를 유지한다. 이 상태에서 r → d/u는 `ERR:END_CUTOFF_UNVERIFIED_USE_Q_W`로 거절되고 모터를 켜지 않는다. d/u의 이름은 물리적 위/아래를 확정한 뜻이 아니라 각각 J/K 전기 방향의 시간 시험이다. a는 기존 5초씩 한 사이클, j/k는 기존 2초씩으로 유지한다.

차단 확인 전에는 부하를 제거하고 눈금 기준을 잡아 r → q 또는 r → w의 0.5초 미세 이동으로 실제 방향과 이동량을 확인한다. 동작 중 손으로 막대를 잡거나 끝에 걸린 채 반복 구동하지 않는다. 멈췄다고 해서 내장 스위치가 차단한 것으로 결론 내릴 수 없다. 기계적으로 막힌 상태와 구분해야 한다.

장시간 시험 활성화 전 필요한 근거는 해당 모델의 제조사/판매자 설명에 양 끝 자동 차단이 확인되거나, 양 끝에서 실제로 모터를 차단하는 외부 리미트 회로가 검증되는 것이다. 확인 후에만 END_CUTOFF_VERIFIED를 true로 변경한다. 짧은 조그로 방향을 먼저 확인하고, 장시간 시험은 r → d 또는 r → u로 한 번씩 수행한다. s/e는 그대로 중지·잠금한다. 기본값의 최대 출력 15초는 내장 스위치 확인을 대체하지 않는다.

최대 길이 도달 신호선이 없으므로 이 스케치는 끝점 도달을 보고하지 않는다. 자동 제어에서 위치를 알아야 하면 별도 끝점 입력이나 위치 피드백을 추가해야 한다. 별도 OrderPalletFeeder의 주문·카메라 연동 코드는 이번 변경에서 수정하지 않았다.
