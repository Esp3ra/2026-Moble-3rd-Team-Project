# 팔레트 이송용 UNO 펌웨어

Arduino UNO가 액추에이터와 벨트 구동을 담당한다. 팔레트를 10초간 밀고 0.5초 대기한 뒤 액추에이터 복귀와 벨트 이송을 함께 시작한다. 기본값으로는 IR1 감지 후 5.5초 더 이송하고, 조립을 가정해 3초 정지한 뒤 다시 이송한다. IR2 감지 후 2초 더 이송하고 정지한다. 액추에이터 복귀와 벨트 정지가 모두 끝나면 회차 완료를 알린다.

| 신호 | UNO 핀 |
| --- | --- |
| 컨베이어 PUL+ / DIR+ | D5 / D6 |
| 액추에이터 드라이버 ENA / IN1 / IN2 | D9 / D7 / D8 |
| IR1 / IR2 출력 | D4 / D2 |

컨베이어 펄스 반주기는 80µs이며 방향 출력은 HIGH다. 센서 입력은 INPUT_PULLUP을 사용하며 LOW를 20ms 연속 감지하면 상태를 확정한다. 펌웨어 변경에 따른 추가 배선은 위 핀 표를 기준으로 확인한다.

## 시리얼 연동

UNO에 업로드하고 115200 baud, New Line을 사용한다. 시작 배너는 `READY UNO_SIM_V1`이다. `a`는 1회 시작, `s`는 전체 정지, `j`와 `k`는 대기 상태에서 액추에이터를 1초간 전진 또는 복귀시킨다. `q`는 QR 인식 기록용이다. `?`는 현재 시간 설정을 조회한다.

시간 설정 명령은 `T 요청번호 IR1이송ms 조립대기ms IR2이송ms`이다. 요청번호는 1 이상이며 세 시간은 500ms 단위다. 이송 시간은 각각 0~25초, 대기는 0~30초이고 정지 상태에서만 변경할 수 있다. 기본값은 5500/3000/2000ms다. 현재 회차에 사용할 값은 시작 시 고정되며 서버는 `TIMING:` 응답으로 적용 여부를 확인할 수 있다.

자동 시작에는 두 IR 센서가 비어 있어야 한다. 각 벨트 운전 구간은 30초에서 오류 정지하며, 조립 대기 종료 시 IR2가 이미 가려져 있으면 정지한다. 로봇 작업은 시간으로 모의한다.

## 개발 경과와 검증

- [#9](https://github.com/Esp3ra/2026-Moble-3rd-Team-Project/pull/9)는 컨베이어 속도 비교 시험, [#6](https://github.com/Esp3ra/2026-Moble-3rd-Team-Project/pull/6)은 액추에이터 및 UNO 제어 초안이다.
- 단독 구동 이후 팔레트 배출과 벨트 출발을 연동했다. QR 위치에서 멈추던 초안을 거쳐 조립 위치는 IR1, 최종 위치는 IR2로 구분했다.
- 제출 스케치는 사용자 실물 시험에 사용된 pallet_system_uno_sim.zip의 UNO 펌웨어다. 사용자로부터 ZIP으로 실물 이송 시험이 성공했다는 결과를 받았다. 이 PR의 검증은 UNO 컴파일이며 별도 장비에서 다시 시험하지 않았다.
- Pi 웹 UI와 주문·DB는 별도 통합 범위다. 이번 펌웨어의 조립 대기는 UNO 내부에서 실행한다.
